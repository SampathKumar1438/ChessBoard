## 2024-05-24 - Descriptive Alt Text as Critical Fallback
**Learning:** Generic `alt` attributes like "image-1" fail to provide any context when images break (e.g., due to incorrect file paths). Descriptive `alt` text is critical not just for screen readers, but as a graceful fallback for visual users when assets fail to load.
**Action:** Always ensure `alt` attributes contain descriptive text about the image content, treating them as essential content rather than just an accessibility compliance checkbox.
