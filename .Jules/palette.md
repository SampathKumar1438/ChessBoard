## 2024-07-07 - Table Accessibility Enhancements
**Learning:** Layout tables require `role="presentation"` to avoid confusing screen readers, and data tables must use proper `<caption>` elements instead of standalone `<th>` elements for titles.
**Action:** Always ensure tables used purely for visual layout have `role="presentation"`, and use semantic `<caption>` tags for table titles rather than misplaced heading elements.
