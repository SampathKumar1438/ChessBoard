## 2024-05-18 - Replacing Generic Alt Text with Descriptive Text

**Learning:** Generic alt text (e.g., "image-1", "photo") provides no value to screen reader users and can be frustrating. Informative images must have descriptive alt text that conveys the image's content or function.

**Action:** Always replace generic alt attributes with meaningful, descriptive text based on the image's content, context, or filename (if descriptive) when implementing or fixing UI components containing images.
