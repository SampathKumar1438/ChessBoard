## 2024-07-24 - Accessibility Learnings from Visual Grids and Galleries
**Learning:** We discovered two common accessibility pitfalls in this HTML codebase. First, image galleries frequently use non-descriptive, generic `alt` text like "image-1" or "image-2", which provides no value to screen reader users trying to understand the content. Second, complex structural elements like HTML `<table>` tags are often used solely for visual presentation (such as drawing a chessboard with 64 empty cells). This causes screen readers to redundantly announce "table, 8 rows, 8 columns" followed by 64 empty cells, leading to a terrible UX. Additionally, `<th>` elements outside of `<tr>` tags are invalid HTML and create unassociated table structure.
**Action:** Always provide descriptive `alt` text for informative images or leave them blank (`alt=""`) if purely decorative. For structural elements used purely for visual layouts (like the chessboard), apply `role="presentation"` and `aria-hidden="true"` to prevent screen readers from parsing the underlying DOM structure. Ensure that tables use valid semantics like `<caption>` for titles and `scope="col"` or `scope="row"` for headers.
