## 2026-05-22 - Descriptive Alt Text for Images
**Learning:** The application was using generic, non-descriptive alt text (like "image-1") for images, which is not helpful for screen reader users and hurts accessibility. Also, file paths in HTML must align with the actual directory structure.
**Action:** Replaced generic alt text with descriptive text derived from the image content/filenames, and ensured image files were placed in the correct 'assets/' directory as expected by the HTML.
