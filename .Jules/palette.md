## 2024-05-18 - Proper Table Accessibility Patterns
**Learning:** Tables are sometimes used strictly for layout purposes (like the chessboard in this project) and sometimes for actual data presentation (like the timetable). It's crucial to explicitly distinguish these for screen readers. Using `role="presentation"` on layout tables prevents screen readers from announcing them as data tables. Conversely, data tables must use proper semantic structure, such as `<caption>` instead of standalone `<th>` elements for table titles, to be correctly parsed and announced.
**Action:** When evaluating table accessibility, first determine its purpose (layout vs. data). Apply `role="presentation"` to layout tables, and strictly enforce semantic elements like `<caption>`, `<thead>`, `<tbody>`, and `<th>` with correct scope for data tables.
