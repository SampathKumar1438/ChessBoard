## 2024-05-31 - Table Accessibility Issues
**Learning:** This project's HTML code pattern sometimes uses tables for layout (requiring `role="presentation"`) and incorrect table structure elements like standalone `<th>` tags instead of semantic `<caption>` tags.
**Action:** When working on similar static pages in this repository, actively check table components to ensure layout tables are properly hidden from screen readers and tabular data tables use structurally valid semantic headers/captions.
